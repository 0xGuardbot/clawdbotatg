## 🛡️ What is Guardbot?

Guardbot is the security and protection layer within the Clawdbot ecosystem.

If Clawdbot executes tasks,  
Guardbot makes sure those tasks are safe, authorized, and intentional.

Guardbot does not spy.  
Guardbot does not interfere unnecessarily.  
Guardbot stands watch.

> *Not a watcher. A guardian.*

- Your system

## 🔐 Core Responsibilities

Guardbot is responsible for:

- 🛂 Authorization & permission checks  
- 🧠 Intent validation before execution  
- 🧱 Boundary enforcement  
- 📜 Policy-based decision control  
- 🚨 Preventing unsafe or unintended actions  

Every action passes the guard.
